The enquiry form opens WhatsApp with a prefilled message; it does not save form entries or require a paid backend.

To publish it free for everyone:
1. Create/sign in to a GitHub account.
2. Create a new public repository named hyd-home-tuition.
3. Upload index.html and the hero image into the repository root.
4. Open Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub Pages to publish the site. The public URL will look like https://YOUR-USERNAME.github.io/hyd-home-tuition/
You can use the actual URL shown in the Pages settings once deployment finishes.

Before publishing, verify phone number, services, classes, and all claims. Replace any content you do not offer.
